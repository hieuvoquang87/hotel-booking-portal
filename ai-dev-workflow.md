# AI Development Workflow

## 1. Analyzing Requirements and Brainstorming

1. Analyze initial requiremnts
2. Make multiple assumptions with initial requirements
3. Add/capture all ideas about the requirements
4. Create draft documents capturing all the ideas and thoughts

## 2. Creating high-level documents

1. Create Assumptions and Trade-offs
2. Create PRD (Production Requirements Description)
3. Create User-flows/data-flow documents
4. Create product feature roadmap

## 3. Creating Architecture documents

1. Create Architecture document
2. Create Progress with milestones to implement the product
3. Create and review tasks for each milestone

## 4. Creating specs and implementation plans

1. Create spec and implemenation plan for each milestone
2. Review and adjust the spec and implementation plan to keep focus on the core requirements.
3. Create UI mock designs for each page
